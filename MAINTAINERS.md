# DustMap Maintainers

## Roles & Responsibilities

Maintainers are responsible for:
- Reviewing pull requests with safety and code quality in mind.
- Reviewing cleanup rule changes (especially those marked `risk = "safe"`).
- Responding to bug reports and data-loss reports with the highest priority.
- Maintaining the release pipeline and security posture.

## Decision Making

- **Lazy Consensus:** Used for routine bug fixes, documentation, refactors, and rule updates.
- **Two Approvals Required:** Any change marked `risk = "safe"` requires two maintainer approvals and verification evidence.
- **RFC Process:** Structural changes to architecture, IPC protocol, safety model, or licenses require a short RFC in `docs/rfcs/`.
